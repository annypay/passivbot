# 0007 — 跨轮次过拟合审计：J5 判定"不冻结这条历史"（2026-09-18）

**一句话结论：把四轮研究在同一份 2021–2026 Binance 历史上做过的试验登记成台账后，试验次数下界是
N = 1805；在这条历史上"挑最好的那一个"经不起样本外与多重检验：J1（池子携带信号）、J3（熬过
多重检验）、J4（折叠稳定）在样本外全部不通过，因此按预注册规则 J5 判定**不冻结这条历史**——
停止在同一份数据上继续调参，只做机制性改动，并把账户守护与冷却阶梯标注为样本外未确认。**

## J5 的四条后果

1. **停止在同一条 2021–2026 历史上继续调参。** 之后不再新增"在同一份数据上挑更好配置"的搜索；
   `c1`（搜索冠军）、`b_red015`、`g_user12h`、`a_allow037` 只能作为**样本内描述**引用。
2. **只做结构性/机制性改动。** 能靠机制论证、不依赖这段历史的改动仍可做——引擎 PR #12 的两个键
   （冷却阶梯是风险塑形；累计已实现亏损口径修的是"瞬时尖峰扣动永久关停"的机制缺陷）属于这一类。
3. **账户守护与冷却阶梯标注"样本外未确认"**：在这条历史上守护类改动的样本外排名不可靠，因此它们
   在实盘上只能当作**风险上限**（降低暴露、限制单币集中度），不能当作已验证的收益来源。
   这与 `g4_hsl_halt_ladder_2026-09-18` 的 K1/K3 一致：阶梯收益中性、第一档取舍在两条腿上相反。
4. **新证据轴**：要改变上述结论，必须引入这段历史之外的证据——新的时间段（2026-09 之后的前向
   纸面/实盘记录）、新的交易所或币池、或与选币无关的机制性论证；在旧历史上再搜一次不算新证据。

## 方法（只读，不新增搜索、不重跑回测、不改引擎）

- **台账**：`artifacts/trial_ledger.json` 把 8 轮里实际评估过的 1810 条尝试逐条登记
  （study + arm/cell + 腿 + 落盘路径），给出 N 的**下界 1805**。下界只统计"有落盘结果且被点名"的
  尝试；被合同声明但从未真跑的格子、优化器未落盘的非 Pareto 候选、没有记录的人工试错都不计入。
- **面板**：月度收益从每个 run 的逐小时权益账本重算（`analysis.json` 不带月度序列）。池 A = 风险
  几何 44 arm × `3y`/`ext`/`pre`；池 B = 守护 + 10k 重放 + 风险几何的 `ext` 并集。
- **CSCV/PBO**：S ∈ {8,10,12,16} × 两种选择口径（max ADG、max ADG×(1−DD)），附半样本 IS→OOS
  斜率与秩相关。退化规则 `D0`（无权益序列/节奏异常）、`D1`（截断）、`D2`（末段恒定 ≥30 天）、
  `D3`（零方差）在**看到任何 PBO 数字之前**写死，并在选择之前整体移除。
- **多重检验**：DSR（含 `Var(SR_trials)` 的横截面代理近似）、MinBTL、平稳自助 SPA 与 StepM
  （B=2000、seed 20260918），N 敏感性 **[92, 200, 500, 1807]**。
- **折叠**：K=3/6，报告折叠冠军的折叠外分位与折叠间平均 Spearman。
- **压力臂**：45 个声明式成本/执行压力臂，明确**不是选择输入**。
- **反模式复核**：`anti_pattern_audit.md` 的 R1–R22，pass/fail/unknown 三态，unknown 必须写清
  缺什么证据。

## 读数的边界

- **PBO 不是亏钱概率**：它度量"在这批 arm 里挑最好的那一个"在这条历史上的脆弱程度。
- **检测不到参数时间旅行与选择来源**（R16/R17）：曲线不记录每个参数何时变得可知，台账也只能记录
  被点名的尝试。
- **N 是下界 ⇒ 惩罚是乐观端**：真实 N 更大时结论只会更强。
- **退化剔除让面板变小**：CSCV 需要矩形面板，池 B 去掉 10/28 后 PBO 的估计方差更大。

## 对实盘决策的影响

- 现有配置模板（发布 g4 门控 profile、TWE 3.0 / 10k + 账户守护）**不变**：本审计不提供更好的点，
  它说明"再在这份数据上挑更好的点"这件事本身不可靠。
- 实盘准入的判断依据要改成**结构性上限 + 前向记录**：暴露上限（TWE / n_positions /
  `we_excess_allowance_pct`）与账户守护作为风险上限，收益预期交给前向纸面/实盘记录来建立。
- 资金与密钥相关的前置条件仍见 [`0002-binance-live-debug-2026-09-17.md`](0002-binance-live-debug-2026-09-17.md)。
