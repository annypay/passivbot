# 回撤解剖：为什么 default_trailing_martingale_long 会亏 73%，以及什么机制才能真正压住它

本文件是本专题的机制底稿。它回答一个具体问题：**73% 的最大回撤是"参数没调好"，还是策略结构决定的？**
答案决定后续所有杠杆的取舍顺序，因此先把它算清楚。

- 口径：Binance USDT-M 永续 1 分钟 HLCV，40 币冻结篮子，T+1 执行（`execution_delay_bars=0`），
  maker 0.0002 / taker 0.0005；风控基准为分钟收盘 `usd_total_equity`。
- 基线：`backtests/binance/2026-09-14T03_40_41`（`annual_analysis.md` 的实际产出目录）。
- 全部为离线本地回测。未联网、未使用凭证、未接触交易所账户、未创建订单。

## 1. 基线风险形态

| 指标 | 数值 |
| --- | ---: |
| 分钟收盘最差回撤 | **73.16%** |
| 期末倍数（`gain_strategy_eq`） | 12.21x |

| 最长水下 | 171.9 天 |
| 成交数 | 69,799 |
| 强平 | 否 |

73.16% 不能直接读作"波动大"。它是**单次事件的一次性结算**：2025-02 → 2025-04 的同一段行情
在多个窗口里重复成为最大回撤（选择窗与全窗 MDD 完全相等即是证据），并且**几乎全部停留在
未实现 PnL**——谷底浮亏约为余额的 73%，而已实现余额回撤仅约 2%。

## 2. 机制：成本基础敞口 × 资产跌幅

### 2.1 关键代码事实

| 事实 | 位置 | 后果 |
| --- | --- | --- |
| `calc_wallet_exposure = qty_to_cost(size, position.price) / balance` | `passivbot-rust/src/utils.rs:255` | TWE 是**成本基础 / 余额**，不是盯市敞口。价格下跌不降低 WE；其他币的已实现亏损侵蚀余额反而抬高 WE 比值 → **下跌途中仍被允许加仓** |
| 入场闸门为 `current_twe >= total_wallet_exposure_limit` | `passivbot-rust/src/orchestrator.rs` | TWEL 是"建仓意图上限"，对盯市回撤**不构成上界** |
| `we_excess_allowance_pct = 0.37`（bounded） | `passivbot-rust/src/entries.rs` | 单币成本敞口可达 `TWEL/7 × 1.37 ≈ 0.29`，一个币即可吃满全部预算 |
| `double_down_factor = 0.94` | `passivbot-rust/src/entries.rs` | 每次补仓 ≈ 前一次的 94%，**5 次补仓打满 1.5** |
| `unstuck` 需 `price ≥ EMA_upper × (1 − 0.0269)` 且 `WE/WEL > 0.466` | `passivbot-rust/src/risk.rs` | 深跌时价格远离 EMA → 唯一内建减仓通道**几乎从不触发** |
| `hsl.enabled = false` | 基线配置 | 没有组合级刹车 |

### 2.2 静态损失界

设建仓后资产价值残留比为 `r`（资产跌到原价的 `r` 倍），满仓成本敞口为 `TWEL`：

```
账户回撤 ≈ TWEL × (1 − r)
```

2025 事件实测资产端约 `r ≈ 0.51`（跌约 49%），`TWEL = 1.5`：

```
预测回撤 ≈ 1.5 × 0.49 = 73.5%
实测回撤 = 73.16%
```

**误差 0.3pp。** 这个恒等式解释了基线的全部尾部回撤，并且是全部对策的出发点。

### 2.3 由此得到的取舍顺序

1. **要压回撤，必须降低 `TWEL × (1 − r)` 中的某一项。** 降低 `(1 − r)` 意味着"在下跌中不要满仓"，
   即降低敞口或让亏损更早变已实现；降低 `TWEL` 意味着永久降低参与度。
2. **纯平仓路径调参对盯市回撤无上界作用。** 下跌中价格在成本**下方**，平仓挂单挂在成本上方，
   根本不成交，浮亏继续累积。平仓参数是**形态**工具，不是**回撤**工具。
3. **"让亏损更早变已实现"能改变 `r`，但代价是水下期。** 它把浮亏换成已实现亏损并清空仓位，
   随后需要重新建仓，因此降 MDD 而**拉长水下期**（本轮实测确认，见 §4）。
4. **回撤与收益在结构上是一对一的。** 任何声称"回撤减半、收益不变"的结果都应先怀疑是过拟合。

## 3. 已封死与已核实的两条路

### 3.1 账户级盯市刹车：已实现，实测劣于静态降敞口

`bot.<side>.risk.wallet_exposure_brake_*`（默认关闭）语义为入场预算按回撤线性缩放，
平仓预算完全不变。

| 配置 | 窗口 | MDD | CAGR | 最长水下 |
| --- | --- | ---: | ---: | ---: |
| 基线（无刹车） | 全窗 3 年 | 80.64% | +82.3% | 179.0 天 |
| `brake_015_045_025` | 全窗 3 年 | 64.90% | +77.9% | 197.3 天 |
| `brake + TWEL 1.0` | 全窗 3 年 | 50.29% | +50.0% | 177.8 天 |
| `combo_twel100_ddf060_ddthr0030`（静态） | 全窗 3 年 | **31.01%** | **+42.1%** | **1.9 天** |

（上表为 v3 保守口径，取自 `dd_tail_research_2026-09-15/tail_drawdown_attribution.md`。）

原因：刹车只拦新入场、不平存量仓；而马丁的收益**主要来自下跌途中的补仓**，
在回撤中收紧入场等于同时削掉它最主要的收益来源。

### 3.2 MFE giveback：已原生实现，且已被证据否决

`close.retracement_base_pct` 就是 MFE giveback，其 MFE 状态由 `TrailingPriceBundle` 的
`max_since_open`（持仓期最高价）与 `min_since_max`（自最高点回撤）承载，见
`passivbot-rust/src/closes.rs::calc_trailing_close_long`。

前序研究 `maxdd_strategy_research_2026-09-14/mfe_research/` 对 `trailing_martingale` 做了
三折 walk-forward + 严格 ablation + 窄邻域联合搜索，结论是
`mfe_enabled_for_final_training = false`：

| 指标（OOS，三折最差） | 参数比较组 | 启用 MFE |
| --- | ---: | ---: |
| 最差 MDD | 6.5479% | 6.5468% |
| 最长恢复 | 49.17 天 | 49.17 天 |
| 最小 ADG | −0.000113 | −0.000110 |
| 几何复利倍数 | 1.0440x | 1.0481x |

**MFE 对回撤的改善约 0.001pp——即没有改善。** 本专题因此不重测 MFE giveback。

## 4. 本轮实测：什么真的动了回撤（口径 A，全窗口 2023-09-12 → 2026-09-12）

种子 = 已发布 profile（`published` 行）。`reference` 是冻结默认基线对照格，

三点读法：

1. **`published` 复现到 4 位小数**（32.916% / +37.67% / 2.6097x），与
   `docs/strategy_profiles.md` 中该 profile 的公布值一致。本专题的复算链与既有证据链同源。
2. **唯一"几乎免费"的收益改进来自平仓侧，不是回撤侧。** `g3_cth0000`
   把 `close.threshold_base_pct` 从 −0.0027 归零，收益从 +37.67% 升到 **+44.36%**，
   MDD 只从 32.92% 升到 33.19%。它不解决回撤，但显著抬高回撤-收益前沿。
   `close.retracement_we_weight`（`g3_crw0005/001`）完全不生效，是本轮的一个阴性结果。
3. **路径止损（unstuck）确实压回撤，但把水下期从 25.6 天推到 463 天**：
   收益-回撤比（CAGR/MDD）从 1.14 掉到 0.67。**它不是可交付的改进**，
   而是"把浮亏换成已实现亏损"的代价的实测证据。

## 5. 结论

- **30% 回撤是可达的**：`g1_tw090`（TWEL 1.5 → 0.9）给出 **29.70% MDD / +34.54% CAGR**，
  同口径下这是唯一同时满足"MDD ≤ 30% 且 CAGR ≥ 25%"的单元。
- **但 30% 不是保证。** 它只是把一次 −49% 的资产事件恰好挡在 30% 以内；
  真正的熊市里 `r = 0.2` 完全可能出现，那时 `TWEL = 0.9` 仍会打出约 72% 的回撤。
  任何"回撤封顶 30%"的表述都必须带上这个条件。
- **想要更高收益，就得接受 32–33% 的回撤**：`g3_cth0000`
  （+44.36% CAGR / 33.19% MDD）比种子在两端都更好，是本轮实质性的收益发现。
