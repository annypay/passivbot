# g4 门控 profile @ TWE 3.0 / 10,000 USDT：回测与尾部实测

本文件是研究的跨 arm 综合结论；每个 arm 的完整深度分析（仓库报告规范固定骨架 + 研究附录）在其自己的 run 目录 `annual_analysis.md` 中，两者数字同源、可独立复算。

## 一、问题与方法

把已发布的 g4 门控 profile 在**同一份冻结数据**上重跑，把总暴露上限从 1.0 提到 **3.0**、起始资金从 100,000 降到 **10,000 USDT**，量出账户能撑到什么程度、什么时候被强平；并按上一轮研究的建议，加一条硬底线（HSL `unified` + `red_threshold=0.10`）做对照。

- 数据集 `3y`：`caches/hlcvs_data/binance__40_coins__2023-08-17_to_2026-09-12__8300950b42789a26`，窗口 2023-09-12 → 2026-09-12。
- 数据集 `ext`：`caches/hlcvs_data/binance__40_coins__2021-03-25_to_2026-09-13__a02b6ae1c140f2b7`，窗口 2021-04-20 → 2026-09-13。
- 资金契约：起始资金 10,000 USDT（发布 profile 100,000），由 `backtest.starting_balance` 驱动全部按余额缩放的仓位。
- 强平契约：`backtest.liquidation_threshold` = 0.05 ⇒ 引擎地板 = 起始资金 × 5%；**触发时引擎在该根 K 线结束回测**（`liquidated=true`），其后数值无意义。
- 判定规则：**J1** TWE 3.0 基线在两条腿上是否被强平（liquidated=true）⇒ 是则判定“该杠杆在本地历史范围内不可实盘”，并给出从起始资金到强平的存活天数。；**J2** 硬底线（unified red=0.10）是否把最差回撤压到基线的 60% 以下、且不触发强平 ⇒ 同时给出 ΔCAGR（pp/年）作为代价。；**J3** 10k 规模对照（TWE 1.0）与发布基线（100k）的全期最差回撤/CAGR 差异 ≤ 1pp ⇒ 判定资金规模效应可忽略；否则量化它。；**J4** we_excess_allowance_pct=0 在同样不发生强平的前提下，最差回撤低于硬底线 arm ⇒ 推荐结构性方案而非熔断。；**J5** 终止式 arm（restart=never）的终值低于硬底线 arm 的 50% ⇒ 判定它不适合作为默认硬底线，仅作为人工决策后的最后一档。
- 所有 arm 都通过运行时开关 `--disable_plotting coin_fills` 关闭逐币成交面板（本机内存约 7.8 GB）；摘要图与全部数据产物不受影响。

## 十、建议

- **TWE 3.0 在本地历史内被强平**：该杠杆不能直接上实盘；任何沿用它的方案必须先解决“在强平之前介入”，而不是等引擎地板。
- 3y 腿硬底线裁决：硬底线未同时满足“回撤 ≤ 基线 60%”与“未强平”。
- ext 腿硬底线裁决：硬底线未同时满足“回撤 ≤ 基线 60%”与“未强平”。
- 3y 腿资金规模裁决：资金规模效应不可忽略，已量化。
- ext 腿资金规模裁决：资金规模效应不可忽略，已量化。
- 组合级熔断（`unified`）在 TWE 3.0 下会明显更频繁触发：它按策略净值计算回撤，满仓时约 −3.3% 行情即触发 10% 阈值，因此它的作用是“压低尾部 + 付出停牌成本”，不解决“高杠杆本身不划算”的问题。
- 结构性替代（`we_excess_allowance_pct=0`）把单槽上界从 58.7% 降到 42.9%，不需要停牌、也不引入 panic 实亏；如果只想要一个“不需要盯盘”的稳健改动，优先它。
- 实盘准入：10,000 USDT 下仍可能有币的初始入场低于交易所最小名义价值（见第八节），上线前用 `passivbot tool entry-regime-probe --balance 10000` 复核一次，或在 `live.filter_by_min_effective_cost` 保持开启的前提下接受这些币不参与。

## 十一、边界

- 历史未崩不等于未来安全；结论只在两条冻结腿与既有执行/成本契约的范围内成立。
- 扩展腿 2021-04-20 起交易、2022 年之前只有 22 个币有数据，且币池是活到 2026 年的当前top40，存在幸存者偏差；早期月份受闸门预热影响，2021-05 事件只能作旁证。
- 引擎的强平线是“权益 ≤ 起始资金 × liquidation_threshold(0.05)”，触发后回测在该根 K 线终止；它是模型的地板，不等同于真实交易所的分层维持保证金，也未计入强平费用与滑点。
- 引擎不模拟保证金/杠杆占用：TWE 3.0 在实盘需要约 30% 初始保证金（10 倍杠杆），分层维持保证金可能让真实强平早于模型地板。
- HSL 触发指标为 min(raw, EMA)，对一天内完成并反弹的闪崩天然迟钝，不能当作插针保险。
- 回测不含真实资金费率、流动性枯竭下的滑点、API 断连与交易所/稳定币对手方风险。
