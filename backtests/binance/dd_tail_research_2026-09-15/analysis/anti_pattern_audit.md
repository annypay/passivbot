# 反模式与泄露审查（v4 契约：T+1 + 币安实际费率）

本文件回答三个问题：(1) 在当前时刻用历史数据跑回测，是否存在模式泄露；(2) 是否存在过拟合
风险，以及如何度量；(3) 哪些"反模式"仍然未被排除。

结论先行：**这份回测仍然不是严格无前视的历史实盘复现**，但它的问题范围已被逐条限定。参数与
币池的选择偏差（R16/R17）是本轮**无法用回测本身消除**的那一类；`next_candle`（R1/R3）是已确认
的模型内前视；其余条目或不适用于本口径，或只有低/中风险且已注明验证方式。

定量审查（PBO 与 walk-forward，见 `overfitting_audit.json`）。

### 本轮相对 v3 的变化

1. **费率从"保守假设"改为币安实际（maker 0.0002 / taker 0.0005）**。本策略 `market_orders_allowed=false`
   且 HSL 关闭，账本为 100% maker，因此**只有 maker 费率实际生效**；taker 费率与
   `market_order_slippage_pct` 仅作用于市价成交（panic 平仓），本策略不会产生这类成交。这意味着：
   - 费率口径修正的影响是**单向且可量化**的（成交数~5–7 万次，每 1bp 都实打实）；
   - 报告必须显式记录 `taker_fills = 0`，否则读者会误以为 taker 费率参与了结果。
2. **执行口径从 T+2 回到 T+1**。v3 的保守边界与 v4 的 nominal 下界**不可混用**；两套 cell 与报告
   并存，任何跨口径比较都必须标注来源。
3. **新增月度收益面板**（`pbo_monthly_returns.csv` / 各 cell 的 `monthly_returns`），使 PBO 可以在
   比半年更细的块上计算。

## 3. 过拟合度量（PBO / walk-forward）

方法与结果见 `report_tools/audit_overfitting.py` 与 `overfitting_audit.json`。要点：

- **CSCV**：把面板切成 S 个连续块，枚举全部"半样本"划分；每划分用一半做样本内、另一半做样本外，
  按年化 Sharpe 选样本内最优配置，记录它在样本外的排名分位。PBO = 该分位不高于中位数的比例。
  对 S ∈ {8, 10, 12, 16} 分别报告，避免单一分块带来的偶然性。结果：PBO = 0.229 / 0.171 / 0.149 /
  0.116（S=8/10/12/16），样本内最优曲线的 Sharpe 从 7.2–7.8 降到样本外约 4.5（IS→OOS 斜率
  −0.26 ~ −0.51）。四组全部低于 0.5，说明这批配置整体携带信号，但"从中挑最好的那一个"本身脆弱。
- **面板口径**：全窗有 37 个自然月分桶，但 CSCV 需要矩形面板，只能用"每条曲线都覆盖"的交集，
  即 20 个月（2023-10 → 2025-05）。这不是人为缩短：`unstuck_off` 在 2025-04 爆仓后不再产生收益，
  交集就是剩下的部分。该截断记录在 `overfitting_audit.json` 的 `panel.truncated_cells`，且它是唯一
  提前结束的曲线。这 20 个月包含 2025 年那轮下跌（baseline 最差月 `2025-02` −31.90%、
  `2025-03` −19.26%），因此面板并非只在平静区间取样。
- **配置池的边界**：38 个 cell 来自同一轮人工杠杆筛选（G1–G6），彼此不独立、含先验判断。因此 PBO
  度量的是"在这批配置里挑最好"这件事的脆弱性，**不是**"策略会亏钱的概率"，也不能替代真正的
  样本外验证。
- **walk-forward**：选择窗（2023-09→2025-09，v4 口径）与已锁定的未见窗（2025-09→2026-09，v3 保守
  口径，锁定后开封）并排报告，落差即为选择偏差的直接观测量。未见窗口径不同这一点在报告中必须标注。

  | 曲线 | 选择窗 MDD / CAGR | 未见窗 MDD / CAGR |
  | --- | --- | --- |
  | default（TWEL 1.5 / ddf 0.94 / thr 0.019） | 73.16% / +128.57% | 80.93% / −27.55% |
  | candidate（TWEL 1.0 / ddf 0.60 / thr 0.030） | 32.92% / +41.40% | 13.90% / +33.55% |

  读法：样本内 default 的 CAGR 优势是 3.1 倍，到未见窗变成亏损，**收益优势没有穿越锁定日**；
  candidate 的优势更小但符号不变。回撤排序在两个窗口一致（73.16% vs 32.92%；80.93% vs 13.90%），
  说明低敞口带来的尾部收缩是结构性差异，而样本内的高收益里相当一部分是这段历史的 beta。这正是
  R16/R17（选择偏差、单段历史）无法被 PBO 消除、只能被 walk-forward 量化的部分。

  注意：未见窗口径为 v3 保守（T+2、3 倍 maker 费），比选择窗的 v4 更严苛，因此这一列对 default
  更不利。两列不可直接相减当作纯"选择偏差"；candidate 在 v3 下反而略好（见 `docs/strategy_profiles.md`
  的敏感性表），所以这一列的方向对两个策略并不对称。

## 4. 本报告不能证明的事项

1. 不能证明 maker 资格：非市价订单按挂单价全额成交并记 maker，真实 GTC 可能穿价成交而成为 taker。
2. 不能证明无前视：R1/R3 的 peek 仍在；no-peek 反事实未做。
3. 不能证明可实盘部署：无盘口队列、部分成交、mark-price 强平、资金费率与真实保证金阶梯。
4. 不能消除选择偏差：R16/R17 仍在；PBO 只量化而不消除它。
5. 不能把两套口径（v3 保守 / v4 币安实际）混编成一条收益曲线。
