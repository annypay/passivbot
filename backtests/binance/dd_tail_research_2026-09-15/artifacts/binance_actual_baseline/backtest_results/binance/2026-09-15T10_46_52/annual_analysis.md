# 最佳候选策略深度分析：`default_trailing_martingale_long`（Binance 永续 1 分钟三年回测）

## 口径与范围

- 策略来源：锁定候选 `default_trailing_martingale_long`，由 `holdout_candidate_lock.json` 的 ops 施加于冻结基线配置 `configs/examples/default_trailing_martingale_long.json`（sha256 `f94b5e5257bbbdf9…`）。
- 三处改动（唯一差异，其余策略与风险参数与基线逐字段一致）：
- 数据为 Binance USDT-M 永续合约 1 分钟 K 线；冻结篮子 40 币（基线候选池 41 币，`MNT` 无 Binance 有效数据被排除）。
- 有效区间（UTC）：2023-09-12T00:01:00Z 至 2026-09-11T23:59:00Z；回测天数 1096.00。
- 执行与成本口径：`execution_delay_bars=0`（T+2 压力约定，信号 candle 完成后额外一整根 K 线的创建/撤销/替换延迟）、`intrabar_fill_order=close_first`、maker `0.0002` / taker `0.0005`。
- 权益口径：`balance_sample_divider=1`（逐分钟采样）的 `strategy_equity`；`btc_collateral_cap=0.0`。
- 年度/月度余额与权益来自逐分钟采样序列（与 `analysis.json` 同分辨率）；成交、PnL 和手续费按 `fills.csv` 的成交标签归属。`fee_paid` 保留源文件的带符号值，净已实现 PnL = `pnl + fee_paid`。
- `fills.csv` 的 `timestamp` 是所属 1 分钟 candle 的**开盘标签**，不是交易所确认的精确成交时刻；按时点归属是本报告的报表约定。
- 本报告是历史模拟结果，不代表未来收益、实际成交价格或流动性。
- 安全边界：本工件由本地离线回测生成，未联网下载数据、未使用凭证、未接触交易所账户、未创建或撤销订单、未启动机器人。

| 审计项 | 数值 |
| --- | --- |
| 审计行数 | 69,799 |
| `activation_index = decision_index + 1 + execution_delay_bars` 违例 | 0 |
| `fill_index >= activation_index` 违例 | 0 |
| 独立 `fill_index` 数 | 63,970 |
| 激活到成交的等待 bar 数（中位 / 最大） | 0.0 / 1,137 |

必须与结论一起阅读的限制：

1. **T+1 全 bar 可成交是模型假设。** 本报告采用 `execution_delay_bars=0` 的保守压力口径，仍不知道订单被交易所接受的精确时刻，也不含盘口队列、部分成交、撤单竞争与真实撮合路径。
2. **maker 身份与费率是假设。** 非市价订单统一按挂单价、maker 费率记账；`GTC` 不代表 maker-only，真实费率与成交顺序可能显著不同。
3. **backtest-only 的下一根 K 线读取（`next_candle`）未被本次消除。** `close.retracement_base_pct = 0.0005 > 0`，close 走追踪分支，因此该 hint 仍参与判定是否展开完整递归 close 梯子；实盘没有这根未来 K 线，本工件也没有 no-peek 对照来量化其净影响。
4. **同 bar 顺序是确定性约定。** 每个币先处理 close、再处理 entry，不是交易所撮合顺序。
5. **参数时间旅行。** 该配置是 2026 年形成的候选，被回放到 2023-09 起的历史窗口；它可以说明「该参数在这段历史数据上的模拟表现」，不能说明「这套参数在 2023 年已经可实盘运行」。候选的选型过程有锁定 holdout（见下节），但 3 年窗口整体并不构成样本外。
6. **强平未被模拟到。** `liquidated = False` 是该模拟的结果，不等于真实保证金体系下不会强平。
