### 执行与 look-ahead 边界

1. **执行时点是模型假设。** 本工件采用 `execution_delay_bars=0`（T+1）、`intrabar_fill_order=close_first`；它不含盘口队列、部分成交、撤单竞争与真实撮合路径。
   该假设的逐笔记录在 `backtests/binance/hsl_npos1_analysis_2026-09-16/artifacts/execution_audit.csv`：4,310 行，`activation_index == decision_index + 1 + 0` 的违例 0 行、成交早于激活的违例 0 行；激活后等待根数的中位数 0.0，最长 1,531。
2. **maker 身份与费率是假设。** 本次 4,310 笔成交全部记为 maker、taker 0 笔。taker 为 0 时，`backtest.taker_fee_override = 0.00055` 与 `market_order_slippage_pct = 0.0005` **对本次结果没有影响**；非市价订单统一按挂单价与 maker 费率记账，`GTC` 不代表 maker-only，真实排队与部分成交仍未被模拟。
3. **同 bar 顺序是确定性约定。** 本次有 764 个分钟含多笔成交（单分钟最多 24 笔），202 个“同币同分钟既有 entry 又有 close”。仅凭 OHLC 无法恢复这些成交的真实先后路径。
4. **参数时间旅行。** 该 profile 形成于 2026 年，被回放到 2021-04-20 起的历史；结论只能表述为“该参数在这段历史数据上的模拟表现”。
5. **强平未被模拟到。** `liquidated = False` 是模拟结果，不等于真实保证金体系下不会强平；资金费率、保证金阶梯与维持保证金均不在回测内。冰点区间内策略权益一度跌至峰值的 52.06%，真实杠杆与维持保证金约束未被建模。
6. **数据完成度。** `backtest_completion_ratio = 1.000000`，回测天数 1,972.00 天；该比值衡量的是请求区间的数据完整度，不是策略稳健性。

## 结果解读

- 余额从 100,000.00 USDT 增至 83,618.25 USDT；策略权益从 100,000.00 增至 83,618.25 USDT，约增长 -16.38%。分析指标 `gain_usd` 为 0.825823 倍，`gain_strategy_eq` 为 0.825823 倍；该指标使用尾部日度权益，因此不应与采样终点直接等同。
- 分段归因：收益最好的自然年是 2022 年（权益 0.00%，余额 0.00%）；年内回撤最深的是 2021 年（47.94%）。全期非完整年 2 个，其余为完整年。
- 风险特征：全期 USD 最差回撤 47.94%，strategy equity 最差回撤 47.94%，最差 1% 均值回撤 36.88%；最长 PnL 峰值恢复期 1,942.62 天，水下时间占比均值 35.76%。PnL Sharpe -0.0962 / Sortino -0.0176，风险调整后的收益质量需要与回撤一并阅读。
- 成交结构：多头 4,310 笔、空头 0 笔；maker 4,310 / taker 0。多头净已实现 PnL -16,381.75 USDT，空头 0.00 USDT。
- 本报告不构成对未来的预测；全部结论只在上述有效区间、执行口径与成本假设下成立。
- 中心事实：策略只在 2021-04-20 至 2021-05-19 之间交易过（30 个自然日，占有效区间的 1.52%），随后 1,942.46 天没有任何成交；全期回撤与 gain 都由这 30 天加一次硬停平仓决定。
- 该 profile 的 long `n_positions = 10`，本次运行的实测最大非零 long 仓位数也是 10，冰点附近槽位被 10 个币同时占满。
- 风险层成交（`close_auto_reduce_*`、`close_unstuck_long`、`close_panic_long`）合计 936 笔，占全部成交的 21.72%；其中 panic 平仓是唯一一次由风险层驱动的全仓退出。
