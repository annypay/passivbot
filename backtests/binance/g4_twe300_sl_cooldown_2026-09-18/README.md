# g4 @ TWE 3.0 单币止损研究（2026-09-18）

在上一轮验证过的 `a_allow000` 几何（allowance 0、TWE 3.0、unified 守护 RED 0.20 / EMA 60 分钟 /
停机 12H）上，落地并验证一个**默认关闭**的引擎键：`bot.<pside>.stop_loss`——以在场均价为基准的
单币硬止损（触发即整仓 reduce-only 离场，随后 `cooldown_minutes` 内禁止该币加仓）。

## 这个 study 回答什么

用户的原始请求有两部分：

1. **2026-06 ZEC 那次"持续加仓后没触发风控"正常吗？它挺过来了吗？这里有没有乐观偏差？**
   → `optimism_audit.md`（Phase A，无引擎改动）。
2. **加一层"永远挂在均价 −15%、触发后冷却 24 小时"的止损。**
   → Phase B 实现该键（默认关闭），Phase C 用 30 个预注册 run 判定它值不值。

## Phase A 结论摘要

* **加仓是被单槽敞口上限停住的**：ZEC 阶梯在 2026-06-05 02:11 停在 42.013 枚（敞口 0.4284 =
  `TWE 3.0 ÷ n_positions 7`），05:34 那笔只有 0.204 枚，之后 28 小时没有入场成交；市场在 06-05
  07:14 打到 250.00（相对在场均价 −43.83%）。
* **账户级守护离触发只差 0.34pp**：3 年原始权益最大回撤 23.05%，而判定量（`min(raw, ema)`）
  峰值 19.66% < RED 0.20；2026-06 单月回撤 20.10%、月收益 +6.81%。
* **15% 硬止损在 3 年腿上是纯成本**：37 次触发里 30 个（81%）被中断的 episode 最终是赚钱的，
  止损合计实现 −16,300（限价层）/ −17,976（市价层），相对持有成本 +17,680 / +19,356。
* **但同一个仓库的先例方向相反**：账户级 RED 从 0.20 收紧到 0.15 在 3y 腿变差，在含 2021-2022
  尾部的全历史腿上把期末倍数从 ×2.32 提到 ×4.35、回撤从 −73.62% 收到 −47.88%。所以判定必须在
  合成"不反弹"腿上做，不能只看 3y。

## Phase B 结论摘要

引擎实现已合入（`bot.<pside>.stop_loss`，默认关闭；用户文档 `docs/stop_loss.md`、子契约
`docs/ai/features/stop_loss.md`）。验证：

* 默认关闭逐位一致：用上一轮冻结配置重跑，`fills.csv` 的 sha256 与已发布 run 完全相同，
  `analysis.json` 指标零差异。
* 机制生效：打开止损后 3y 腿产生 42 笔 `close_stop_loss_long`，冷却窗口内入场成交 0 笔。
* 无交易所常驻 stop 单：触发在引擎自己的采样循环里，是**已知缺口**（见 `issue/0007`）。

## Phase C 判定

30 个 run 全部完成（6 臂 × 5 腿），判据阈值在 `report_tools/sl_replay.py` 的 `THRESHOLDS` 里
**先于回放**固定：

| 判据 | 结果 | 读数 |
| --- | --- | --- |
| S0 默认关闭逐位一致 | **PASS** | 三条真实腿的 `fills.csv` sha256 与上一轮已发布 run 完全相同、指标零差异、零止损成交 |
| S1 机制 | **PASS** | 3y 腿 42 笔止损成交；30 个 run 的冷却窗口内入场成交全部为 0 |
| S2 合成单币崩塌尾部改善（市价档） | **PASS** | 最差回撤 30.09% → 20.72%（改善 9.37pp） |
| S3 真实腿代价 ≤25% | **FAIL** | 原生 3 年窗终值退化 **41.6%**（×4.754 → ×2.777） |
| S4 限价档不得优于市价档 | **PASS** | 合成单币腿：限价 23.06% ≥ 市价 20.72% |
| S5 尾部收益在悲观档成立 | **PASS** | S2 用的就是 market 档 |
| S6 插针代价 | **PASS** | Phase A 普查：卖在低点占 13.51% < 25% |
| S7 2026-06 锚点 | 报数 | 基准 −20.10% / +6.80%；止损臂 −14.51% / +4.56% |

逐腿读数（终值倍数 / 最差回撤）：

| 臂 | `3y` | `ext` | `pre` | `synth_a` | `synth_b` |
| --- | --- | --- | --- | --- | --- |
| `s0_off` | ×4.754 / 23.05% | ×2.324 / 76.56% | ×0.610 / 76.56% | ×3.799 / 30.09% | ×1.359 / 72.81% |
| `s1` −15%/24h/市价 | ×2.777 / 20.64% | ×3.490 / 37.19% | ×1.244 / 37.19% | ×2.770 / 20.72% | ×2.212 / 34.45% |
| `s2` −15%/4h/市价 | ×2.761 / 21.75% | ×4.010 / 35.73% | ×1.457 / 35.73% | ×2.709 / 22.92% | ×1.667 / 48.78% |
| `s3` −25%/24h/市价 | ×3.487 / 22.02% | ×1.783 / 70.65% | ×0.608 / 70.65% | ×3.458 / 22.02% | ×2.292 / 40.43% |
| `s4` −15%/24h/限价 | ×2.799 / 23.05% | ×3.663 / 36.54% | ×1.268 / 36.54% | ×2.795 / 23.06% | ×1.750 / 48.58% |
| `s5` −15%/无冷却 | ×2.789 / 21.59% | ×4.260 / 33.48% | ×1.525 / 33.48% | ×2.710 / 22.81% | ×1.675 / 51.42% |

**读法**：止损在**没有尾部**的样本里是成本（原生 3 年窗终值 −41.6%），在**有尾部**的样本里是保险
（全历史腿 ×2.32 → ×3.49、样本外腿 ×0.61 → ×1.24、三币崩塌腿 ×1.36 → ×2.21 且回撤腰斩）。
用户给定的 24 小时冷却在三条真实腿上都只有成本：`s5`（冷却 0）在 `3y`/`ext`/`pre` 上都不差于 `s1`。
完整读数与待决策见 `issue/0007-g4-twe300-sl-cooldown-2026-09-18.md` 与 `artifacts/sl_analysis.json`。
