# g4 尾部风险研究：单币/多币归零与账户级风控的实测结论

本文件是研究的跨 arm 综合结论；每个 arm 的完整深度分析（仓库报告规范固定骨架 + 研究附录）在其自己的 run 目录 `annual_analysis.md` 中，两者数字同源、可独立复算。

## 一、问题与方法

核心问题：在马丁格尔入场结构下，账户会不会被“单个币归零”或“多个币同时崩塌”一波带走？开启/关闭 HSL 是否改变这类风险？`pside`/`unified` 组合级信号是否有效？还有哪些不显著伤害盈利的黑天鹅风控？

- 预注册：27 个 arm 的声明式改动、事件识别规则、冲击水平与判据全部在 `artifacts/variant_input.json` 中先行登记，跑完不追加挑选。
- 数据集 `3y`：`caches/hlcvs_data/binance__40_coins__2023-08-17_to_2026-09-12__8300950b42789a26`，窗口 2023-09-12 → 2026-09-12。
- 数据集 `ext`：`caches/hlcvs_data/binance__40_coins__2021-03-25_to_2026-09-13__a02b6ae1c140f2b7`，窗口 2021-04-20 → 2026-09-13。
- 数据集 `synth_a`：`caches/hlcvs_data/binance__40_coins__2023-08-17_to_2026-09-12__synthetic_collapse_a`，窗口 2023-09-12 → 2026-09-12（合成派生 bundle）。
- 数据集 `synth_b`：`caches/hlcvs_data/binance__40_coins__2023-08-17_to_2026-09-12__synthetic_collapse_b`，窗口 2023-09-12 → 2026-09-12（合成派生 bundle）。
- 判定规则：**J1** 某账户级 arm 在两腿 ΔCAGR ≥ −0.5pp/年 且事件内最差回撤下降 ≥30% ⇒ 推荐启用，取满足条件的最大 red_threshold。；**J2** 扩展腿（5.4 年）最差 DD < 20% 且合成单币归零损失 ≤ 20% ⇒ 判定单币归零不构成一波带走；给出同时归零的临界币数 k* = 判据阈值 / 单币 WE 上界。；**J3** 任一 arm 出现 liquidated=true 或最差 DD > 50% ⇒ 上实盘前必须结构性降杠杆（TWE ≤ 0.8 或 n_positions ≥ 10）。；**J4** 合成注入显示引擎在崩塌中仍持续加仓、且损失超过 WE 上限 ⇒ 升级为结构性修正工单（本 PR 不改引擎）。
- 所有 arm 都通过运行时开关 `--disable_plotting coin_fills` 关闭了逐币成交面板（本机内存约 7.8 GB，面板是单次 run 的内存峰值）；摘要图与全部数据产物不受影响，各 arm 报告在 `## 口径与范围` 中声明。

## 七、对实盘的处置建议

- 单币归零是**结构性有界**的：任一币归零最多损失它的敞口峰值（本研究的实测上界见第四节），因此“被一个币一波带走”在引擎层面不成立；真正的尾部来自多币同时崩塌以及恢复基数被打掉。
- 没有账户级 arm 同时满足预注册判据“代价 ≤0.5pp/年 且事件内回撤下降 ≥30%”：账户级熔断在历史窗口里要么近乎休眠（阈值 0.15），要么明显牺牲收益（阈值 0.10）。
- 账户级熔断只对**有持续性的崩盘**有效：触发指标是 `min(raw, EMA)`，一天内完成并反弹的插针不会被拦截，必须写进运营预期，不能把它当作闪崩保险。
- 阈值口径必须先统一：从 `coin` 切到 `pside`/`unified` 时，`red_threshold=0.15` 的含义从“单币约 2% 账户”变成“账户 −15%”，两者不可直接比较。
- 结构性降杠杆（`total_wallet_exposure_limit` / `n_positions` / `we_excess_allowance_pct`）是唯一**确定**压低尾部上界的手段，代价近似线性；任何叠层（熔断、对冲）都必须先与它比较。
- 实盘终止规则（建议）：把账户级熔断的 `restart_after_red_policy` 与 `no_restart_drawdown_threshold` 显式写成“跌破 X% 永久停止”，而不是依赖人工盯盘；X 的取值见第六节 J1 的候选比较。
- 未覆盖：交易所/稳定币对手方风险、真实退市流程、崩盘中的真实滑点与 API 断连；这些只能在运营层面用“盘外留存/利润划出”与资金分散处理（阶段 B）。

## 八、未覆盖风险与非目标

- 历史未崩不等于未来安全；结论只在两条冻结腿与合成情景的范围内成立。
- 扩展腿 2021-04-20 起交易、2022 年之前只有 22 个币有数据，且币池是活到 2026 年的当前top40，存在幸存者偏差；早期月份受闸门预热影响，2021-05 事件只能作旁证。
- HSL 触发指标为 min(raw, EMA)，对一天内完成并反弹的闪崩天然迟钝，不能当作插针保险。
- 合成情景是价格路径注入，不是历史事实，也不等价于真实退市流程（无撮合/无交易所公告）。
- 回测不含交易所/稳定币对手方风险、真实期权与资金费率成本、真实流动性枯竭下的滑点与API 断连；这些必须在报告里作为未建模风险列出。
- 期权/凸性对冲与“盘外留存（operating float）”属于阶段 B：本地没有期权链历史，无法与回测同口径比较，只能做成本预算与规模框架，不能伪造收益数字。
- 本 PR 不改引擎、不改发布 profile、不启动实盘；任何 profile 修订都应另开 PR 并重新走研究-验证流程。
